  <action>
Create backend/tsconfig.json with Node.js/CommonJS configuration:

```json
{
  "compilerOptions": {
    "target": "ES2020",
    "module": "commonjs",
    "lib": ["ES2020"],
    "outDir": "./dist",
    "rootDir": "./src",
    "strict": false,
    "allowJs": true,
    "checkJs": false,
    "esModuleInterop": true,
    "skipLibCheck": true,
    "forceConsistentCasingInFileNames": true,
    "resolveJsonModule": true,
    "moduleResolution": "node",
    "allowSyntheticDefaultImports": true,
    "sourceMap": true,
    "declaration": false,
    "noImplicitAny": false,
    "strictNullChecks": false,
    "strictFunctionTypes": false,
    "noUnusedLocals": false,
    "noUnusedParameters": false,
    "noImplicitReturns": false,
    "noFallthroughCasesInSwitch": true,
    "types": ["node"]
  },
  "include": ["src/**/*"],
  "exclude": ["node_modules", "dist", "src/**/*.spec.ts", "src/**/*.test.ts"]
}
```

Key configuration choices:
- `"allowJs": true` enables incremental migration (JS files can coexist with TS)
- `"strict": false` initially to avoid overwhelming errors
- `"module": "commonjs"` matches existing backend module system
- `"outDir": "./dist"` for compiled JavaScript output
- Strict checks disabled during migration, will be enabled in Wave 6
  </action>

    - Contains "rootDir": "./src" (source directory)
    - Contains "strict": false (relaxed mode for migration)

Create frontend/tsconfig.json with React-specific configuration:

```json
{
  "compilerOptions": {
    "target": "ES2020",
    "lib": ["ES2020", "DOM", "DOM.Iterable"],
    "jsx": "react-jsx",
    "module": "ESNext",
    "moduleResolution": "bundler",
    "resolveJsonModule": true,
    "allowImportingTsExtensions": false,
    "isolatedModules": true,
    "noEmit": true,
    "strict": false,
    "allowJs": true,
    "esModuleInterop": true,
    "skipLibCheck": true,
    "forceConsistentCasingInFileNames": true,
    "allowSyntheticDefaultImports": true,
    "noUnusedLocals": false,
    "noUnusedParameters": false,
    "noImplicitReturns": false,
    "noFallthroughCasesInSwitch": true,
    "types": ["node"],
    "baseUrl": "src"
  },
  "include": ["src/**/*"],
  "exclude": ["node_modules", "build", "dist"]
}
```

Key configuration choices:
- `"jsx": "react-jsx"` enables React 17+ JSX transform (no need to import React)
- `"allowJs": true` enables incremental migration
- `"noEmit": true` since react-scripts handles compilation
- `"lib": ["DOM", "DOM.Iterable"]` for browser APIs
- `"moduleResolution": "bundler"` for modern bundler compatibility
- Strict checks disabled during migration, will be enabled in Wave 6
